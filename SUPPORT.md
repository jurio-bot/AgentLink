# Support AgentLink

AgentLink is an early-stage project building persistent, permissioned, recoverable execution infrastructure for AI workers.

We welcome support from individuals, patrons, companies, cloud providers, research partners, and other organizations that want to help the project move faster without requiring the AgentLink core IP to be sold or opened.

## Ways to support

### Individual supporters / patrons

Individuals can express interest in supporting AgentLink as a patron or recurring supporter.

Support may be used toward:

- cloud and compute costs
- test devices and hardware
- security review and testing
- company / IP setup costs
- demo and documentation work
- third-party onboarding experiments
- reliability and failure-injection testing

A formal payment channel will be published only after the appropriate account, legal, accounting, and identity setup is ready.

### Corporate sponsors

We are open to sponsorship from companies that want to support reliable AI-agent infrastructure.

Possible forms include:

- direct project sponsorship
- cloud / GPU / API credits
- hardware or test-device support
- engineering or security review support
- event / demo sponsorship
- research collaboration
- enterprise design-partner PoCs

Corporate support does not automatically grant ownership of AgentLink core IP, exclusivity, or control over the public roadmap. Any such rights would require a separate explicit agreement.

### Strategic patrons

We are also interested in longer-term patrons who want to support the AgentLink mission while allowing the project to remain technically independent and model-agnostic.

A strategic patron may support infrastructure, R&D, commercialization, international expansion, security work, or specific public technical demonstrations.

### In-kind support

Useful non-cash support can be just as valuable at this stage:

- cloud credits
- GPU / compute capacity
- development hardware
- test devices
- security review
- legal / IP guidance
- enterprise sandbox access
- introductions to design partners or investors

## What supporters receive

Supporter benefits will depend on the support type and any applicable agreement. Potential non-equity recognition can include:

- public acknowledgment, if desired
- supporter / sponsor listing
- early demo briefings
- technical update summaries
- participation in selected public or design-partner discussions

No equity, token, investment return, tax deduction, product guarantee, exclusivity, or IP right is implied by informal support or public recognition.

## Important legal / accounting note

AgentLink is currently being structured as a project and future company. Until a formal support/payment channel is published, this repository is collecting **support and sponsorship interest**, not representing that contributions are tax-deductible charitable donations.

Any financial contribution will be accepted only through an appropriate documented channel with the necessary legal and accounting treatment.

## Interested in supporting AgentLink?

Open a public Issue with a non-confidential note, or contact the project owner through the GitHub profile associated with this repository.

For confidential sponsorship, investment, or strategic-partner discussions, please avoid posting sensitive commercial information in a public Issue.
