# Public Roadmap

This roadmap describes intended directions, not guaranteed delivery dates.

## Now

- harden durable job / receipt semantics
- improve recovery behavior under interruption
- quantify reliability with failure injection
- separate authority / approval state from ordinary execution state
- improve worker capability / availability handling
- build repeatable third-party onboarding
- recruit initial enterprise design partners

## Next

- publish safe reproducible technical demos
- package a narrow enterprise deployment path
- improve observability and audit exports
- evaluate multi-worker conflict-control strategies
- add model/provider lanes while keeping the execution substrate model-agnostic
- perform structured threat modeling and security review

## Later

- enterprise deployment profiles
- broader cloud / edge worker portability
- richer policy and authority controls
- external developer / partner interfaces
- standardized evaluation harness for long-running agent execution

## Success signals

The project should be judged by measurable execution quality, not feature count alone:

- successful third-party onboarding
- completion rate
- recovery rate
- duplicate side-effect rate
- human intervention rate
- reliable permission enforcement
- paid design-partner use
