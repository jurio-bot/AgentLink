## 向いているケース

- Make / n8n / Python / API / AI Agentの小規模自動化を設計したい
- 「AIに任せる部分」と「人が残る部分」を先に決めたい
- timeoutや再試行時の二重実行を設計段階で考えたい
- 導入前後で工数・エラー・手戻りなどを比較したい

## 設計で残すもの

1. 現状の作業と例外
2. Trigger / Action / Output
3. deterministic / AI-assisted / human decision の分離
4. 外部副作用とidempotency key
5. unknown outcomeのreconcile方法
6. KPI baseline

## 含まれないもの

- 本番実装
- セキュリティ監査の保証
- 法務・税務判断
- 特定ツールの導入成果保証
- 工数削減や売上向上の保証
