# Enterprise Design-Partner PoCs

AgentLink is looking for a small number of design partners with narrow, measurable workflows where AI-agent execution can be tested safely.

These are **working commercial hypotheses**, not fixed list prices or guarantees.

## PoC A: Persistent AI Operations Worker

For a repeatable business workflow that spans multiple steps or systems.

Examples:

- research → summarize → update internal knowledge → notify
- support intake → classify → collect context → draft resolution → escalate
- engineering monitoring → inspect state → prepare approved remediation

What we measure:

- completion rate
- manual interventions
- interruption recovery
- duplicate action rate
- time saved

Typical working shape:

- 2 to 4 weeks
- one narrow workflow
- agreed success criteria before start

## PoC B: Secure Agent Execution Gateway

For organizations that want an AI agent to operate inside a controlled execution environment without giving it unrestricted remote-control authority.

What we evaluate:

- scoped permissions
- approval boundaries
- action receipts
- worker health and recovery
- operator intervention

Typical working shape:

- 3 to 6 weeks
- sandbox or non-critical environment first
- explicit action boundaries

## PoC C: Multi-Agent Business Operations Cell

For a narrow objective where 2 to 5 coordinated workers can outperform a single worker while preserving ownership and traceability.

Examples:

- research + drafting + verification
- monitoring + triage + remediation preparation
- lead discovery + research + outreach preparation
- issue triage + testing + documentation

What we measure:

- throughput
- duplicate task rate
- conflict rate
- completion time
- human coordination time

## Commercial principles

- AgentLink core IP remains private.
- Customer-specific configuration and integrations can be delivered without transferring core platform ownership.
- Every PoC should have quantitative success criteria.
- Paid PoCs are preferred when there is real business value.
- Sensitive, legal, financial, identity, privacy, or irreversible actions remain subject to appropriate human control.
- No claim of fully autonomous operation is made where that would be unsafe or inappropriate.

## Good design-partner profile

A strong first partner usually has:

- an active AI / DX initiative
- a repeatable digital workflow
- a safe sandbox or non-critical starting point
- measurable labor or time cost
- an internal champion who can sponsor a test
